# FocusCull 1.4.1 — HIF 10-bit 支持 + 实拍回归

> 连拍一千张，只想留下真正合焦的那几张。  
> FocusCull 把清晰度地图交给 **Metal GPU**，把主体理解交给 **Apple Neural Engine**，让 M 芯片在你的 Mac 上完成一次真正的本地初筛。

FocusCull 是一个原生 macOS 连拍照片初筛工具，专为**生态摄影、航空摄影、体育摄影、汽车/摩托车追焦**而做：一次快门几百张，回家不用再从第一张开始逐张放大。

它不修图、不生成、不做审美判断，只做第一道初筛：先把明显失焦、不够锐、没必要放大看的照片挑出来，让你把时间留给真正值得比较的那几十张。

## 这些场景，FocusCull 是为你做的

- **生态 / 鸟类**：一次几百张飞版，最怕翅膀尖清楚、鸟眼软了；背景树枝和羽毛纹理还比主体锐。
- **航空**：起飞、降落、编队、航展，一架飞机几十张连拍，缩略图根本看不出机头/座舱有没有合焦。
- **体育**：30 张/秒，一场比赛几千张，要在一堆相似动作里找决定性瞬间，还要看脸和眼睛。
- **汽车 / 摩托车追焦**：车身要实、背景要拉丝，轮毂和地面细节却容易抢焦；骑手头盔/脸部是否清楚，决定这张能不能用。

共同点是：**拍的时候怕错过，选的时候怕看漏；真正能用的只有那一两张，却要从几千张里找。**

## 这次更新

### HIF / HEIF 10-bit 与更广的格式兼容
- 新增 `.HIF` 支持（HEIF / HEVC 10-bit；Canon、Sony 等新机型会使用这种扩展名）。
- 未知图片扩展会由 ImageIO 读取内容判断，不再只依赖扩展名白名单。
- 用 **519 张实拍飞机 HIF 照片**（Sony A7R V / 6240 × 4160 / 10-bit）做全量回归：519 / 519 解码成功，0 个分析错误，App 内并发分析约 5.3 秒（含 AI 主体识别；命令行串行模式约 26 秒）。
- 205 张判为合焦，314 张进入疑似失焦 / 人工复核。

### 菜单栏常驻：关了窗口，也别丢了工具
- 关闭主窗口或按 `⌘W` 后，FocusCull 继续留在 macOS 右上角菜单栏。
- 点击菜单栏图标即可拖入图片或文件夹，或用「打开文件夹…」「添加图片…」「添加文件夹…」快速开始。
- 面板显示照片数、疑似失焦数和分析进度。
- 一键「显示主窗口」「设置…」，以及「彻底退出 FocusCull」。
- 关闭窗口不是退出应用；彻底退出请用菜单栏按钮或 `⌘Q`。

### 人物合焦框重做
- Vision 人脸检测优先锁定人脸，人物照片的合焦框现在会落在脸上。
- 人脸过小或未检出时，依次回退到人体、动物、Metal 合焦区域。
- 飞机、鸟类、汽车、自行车、摩托车保留 Metal 合焦区域，避免被零散物体框带偏。

### 四套主题，点击即换
- **FocusCull**：薄荷绿 · 清爽玻璃
- **Adobe**：Adobe 蓝 · 冷调专业
- **Final Cut Pro**：紫红 · 剪辑台氛围
- **DaVinci**：橙色 · 调色台质感
- 主窗口与设置窗口即时切换。

### 操作记录
- 设置新增「记录」页：载入分析、追加、删除、设置变更。
- 支持导出带 UTF-8 BOM 的 CSV，可直接用 Excel / Numbers 打开。
- 最多保留 800 条，本机持久化，不上传。

### AI 主体增加自行车、摩托车
筛选条现在包含：全部、飞机、鸟类、动物、人物、汽车、自行车、摩托车、其他。

### Metal GPU + Neural Engine 协同
- 清晰度：Metal Compute 重建局部清晰度地图。
- 主体/人脸/人体/动物/显著物体：Vision 自动调度 Apple Neural Engine 与 GPU。
- 状态栏、大图底栏和设置页均显示计算引擎。

## 为什么为 Apple Silicon 重写

- **原生 Swift / SwiftUI**，不是 Electron，也不是浏览器壳。
- **Metal Compute**：1100px 灰度图、分离式模糊、方向 Laplacian、重叠分块，全部在 GPU 上完成。
- **统一内存**：解码后的图像不必在 CPU / GPU 之间反复拷贝。
- **Neural Engine**：Vision 在本机完成图像分类、人脸、人体、动物和显著物体检测。
- **完全本地**：没有云端、没有上传、没有账号。

在 M4 Max 上，100 张样张的完整分析约 **1.82 秒**（含解码）。Metal 不可用时自动回退 CPU，Intel Mac 也能运行。

## 安装

1. 下载 `FocusCull-1.4.1-macOS.zip`。
2. 解压，把 `FocusCull.app` 拖进「应用程序」。
3. 双击打开。

应用使用 ad-hoc 签名，未经过 Apple 公证。若系统提示无法验证开发者，请右键点击应用 →「打开」。

系统要求：macOS 14+，Universal（Apple Silicon / Intel）。

## 验证

- Metal 与 CPU 在同一批样张上输出一致的评分和基础合焦框。
- 真实人像与绘画人像均验证人脸框优先。
- 自行车、摩托车样张验证分类映射。
- 四套主题实时切换，操作记录可持久化并导出 CSV。
- 关闭主窗口后进程继续驻留菜单栏；菜单栏面板支持拖入、打开 / 追加、显示主窗口和彻底退出。
- Universal 二进制、ZIP 解压、代码签名验证通过。
